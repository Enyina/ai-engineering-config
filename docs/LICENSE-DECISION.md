# Public product licensing decision

The repository is public, but no root `LICENSE` file has been selected. Public access is not the same as an open-source software license.

Before advertising this as open source or publishing packages, choose a license covering code and documentation, and audit any copied assets or third-party dependencies.

**Options for the owner to decide:**

- **Apache License 2.0:** Permissive reuse with explicit patent-related protections and notice requirements.
- **MIT License:** Short, permissive, familiar for developer tooling.
- **Source-available terms:** If redistribution, hosted derivatives or commercial reuse should be limited; this is not the same as an OSI-approved open-source license and requires careful legal drafting.

This project may be used locally by its author and contributors as permitted by law and GitHub terms, but do not claim non-contributor redistribution rights until licensing is explicit.

**Not done:** No license was chosen on the owner's behalf and no old commit histories were made private. Current licensing and trademark availability require separate confirmation before public launch.
