# Security & Compliance
Never commit credentials, tokens, cookies, session files, SSH keys, private binaries, customer data, or company-owned instructions. Only operate in repositories with appropriate authorization. Keep personal configuration separate from **every** employer's code, policies and credentials. Never migrate one employer's rules into another workspace; see [Trust Domains](TRUST-DOMAINS.md). Never bypass DRM, anti-cheat, authorization or licensing restrictions. Use independent code and original or authorized assets. Agent permissions must remain least-privilege. Review and backup before restore/reset.
