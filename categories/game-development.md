# Games / Reverse Engineering (opt-in)
- First deliver a playable vertical slice, then evolve mechanics using measured playtesting.
- Study mechanics and observable behavior from legally accessible references; implement independent code and original assets.
- Prioritize frame time, deterministic testable core logic, input latency, controller support, gameplay feel and browser/Mac performance.
- Do not circumvent anti-cheat or DRM, redistribute ripped assets, or claim full recreation from a short demo.
